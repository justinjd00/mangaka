# Bundled models

Both files are VRM 0.x models from the `vroid/beta` folder of
[github.com/madjin/vrm-samples](https://github.com/madjin/vrm-samples). They are
unmodified. The licence fields below are copied from each file's own
`extensions.VRM.meta`.

| | `fumiriya.vrm` | `shino.vrm` |
|---|---|---|
| Title | Sakurada Fumiriya | Sendagaya Shino |
| Licence (`licenseName`) | CC0 | CC0 |
| Commercial use (`commercialUssageName`) | Allow | Allow |
| Allowed users (`allowedUserName`) | Everyone | Everyone |
| Other licence URL (`otherLicenseUrl`) | empty | empty |

Never add a model whose own VRM metadata does not say CC0.
