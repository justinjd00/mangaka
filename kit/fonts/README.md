# Fonts

Embedded in every page as base64 WOFF2; the WOFF 1 files are only read to
measure text (`kit/lettering.mjs`). The files come from the Fontsource
packages of the two fonts (Latin subset).

| File | Font | Source project | Licence |
|---|---|---|---|
| `comic-neue-latin-700-normal.woff`, `.woff2` | Comic Neue Bold (dialogue, captions) | https://github.com/crozynski/comicneue | SIL Open Font License 1.1, `LICENSE-comic-neue` |
| `bangers-latin-400-normal.woff`, `.woff2` | Bangers (sound effects) | https://github.com/googlefonts/bangers | SIL Open Font License 1.1, `LICENSE-bangers` |
